Dane i cel dostępu

Program korzysta z Google Drive API, aby zapisywać przygotowane paczki materiałów prawnych na koncie właściciela projektu. Używa wyłącznie zakresu drive.file. Wyszukuje metadane własnych folderów, w tym identyfikatory, nazwy, folder nadrzędny i prywatne znaczniki aplikacji, oraz przesyła nowe pliki wynikowe.

Obecna implementacja nie pobiera treści istniejących dokumentów użytkownika z Dysku, nie odczytuje Gmaila, kontaktów ani kalendarza i nie żąda hasła do konta Google. Autoryzacja odbywa się w Google.

OAuth obejmuje pliki utworzone przez aplikację lub jawnie jej autoryzowane. Przeniesienie takiego pliku poza folder aktualizatora nie cofa jego autoryzacji. Nie należy udostępniać aplikacji dodatkowych plików.

Przechowywanie i zabezpieczenia

Identyfikator klienta, sekret klienta i token odświeżania przechowywane są w GitHub Actions Secret prywatnego repozytorium. Podczas uruchomienia są udostępniane środowisku wykonawczemu; token dostępu jest uzyskiwany automatycznie. Dane uwierzytelniające nie są przeznaczone do publikacji na tej stronie ani w repozytorium strony.

Pliki wynikowe pozostają na Dysku do czasu usunięcia przez właściciela. Uploader nie usuwa ich automatycznie. Kopia wyniku w GitHub Actions ma ustawioną retencję 14 dni, ale może zostać usunięta wcześniej przez kolejny przebieg. Punkty wznowienia po błędzie mają retencję 7 dni i są usuwane po udanej publikacji. Logi podlegają ustawieniom retencji GitHub Actions.

Udostępnianie i usługodawcy

Google obsługuje autoryzację i przechowywanie plików na Dysku. GitHub obsługuje wykonanie programu, sekrety, logi, artefakty i hosting strony. Dostęp do zasobów projektu zależy także od uprawnień nadanych przez właściciela w tych usługach. Program nie tworzy publicznych linków do wyników.

Dane Google nie są wykorzystywane przez ten projekt do reklam, sprzedaży, profilowania ani trenowania modeli AI. Ich użycie ogranicza się do opisanej funkcji. Korzystanie z informacji otrzymanych z Google API podlega Google API Services User Data Policy, w tym wymaganiom Limited Use.

Cofnięcie dostępu i usunięcie

Dostęp można cofnąć w połączeniach konta Google. Aby zatrzymać kolejne uruchomienia, usuń sekret OAuth lub wyłącz workflow w GitHub. Cofnięcie dostępu nie usuwa automatycznie wcześniejszych plików.

Pliki i foldery na Dysku oraz artefakty i logi GitHub należy usuwać w odpowiednich usługach. Usunięcie danych podlega również mechanizmom kosza i retencji tych usług. W razie potrzeby skontaktuj się z opiekunem projektu.

Ta strona

Strona nie zawiera formularza logowania, skryptów analitycznych ani własnych mechanizmów śledzenia. GitHub Pages zapisuje adresy IP odwiedzających dla bezpieczeństwa zgodnie z polityką prywatności GitHub. Usługi Google działają zgodnie z polityką prywatności Google.

Zmiany

Przed zmianą zakresów OAuth, sposobu przetwarzania danych lub udostępnieniem programu innym użytkownikom należy zaktualizować tę politykę oraz konfigurację Google.
